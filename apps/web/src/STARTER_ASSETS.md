# IconForge starter assets

The five SVG shapes in `starter-library.ts` (Home, Search, Plus, Check, Arrow right) were drawn for this repository. They are part of the MIT-licensed project; the copyright holder is named in the root `LICENSE` file. The browser records `MIT`, the copyright attribution, the starter source path, and the SHA-256 of each original SVG in project provenance. It saves the original SVG bytes in `.iconproj` backups.

The source coordinates are authored on a 24 × 24 grid and scale into the selected project grid when picked. Each saved source uses the selected grid and the default 1.75 stroke width. These are small editable examples, not a comprehensive icon collection.
