# Canonical Schemas v1 (Normative)

This is the **single normative definition** of the persisted project model, the command envelope and the V1 command registry. `PROJECT_MODEL.md` explains intent; `AUTOMATION_CONTRACT.md` describes adapters. Where any document disagrees with this one, this one wins.

Representation: TypeScript types are the source; JSON Schema 2020-12 is generated from them and checked in CI (drift fails the build). Runtime validation uses the generated schemas. Command payloads reject unknown properties (`additionalProperties: false`). Project readers preserve unknown properties **only** under `extensions["<reverse-dns-namespace>"]`; anywhere else, unknown properties are a load error.

## 1. Numeric model (ADR-018)

```ts
/** Canonical coordinate unit is the icon's viewBox unit. */
const QUANTUM = 0.001;                 // persisted coordinates are multiples of QUANTUM
type Coord = number;                   // invariant: Math.round(v / QUANTUM) * QUANTUM === v (after canonical formatting)
```

- Every geometry-producing command quantizes its output before commit (round-half-even on the integer `v / QUANTUM`).
- Transcendental functions (`sin`, `cos`, `atan2`, `pow`, `sqrt` of non-squares) may be used **only inside command handlers**; their quantized result is persisted. The compiler and validators use only `+ − × ÷`, comparison and quantization.
- Serialization formats numbers with the canonical formatter (shortest round-trip, no exponent, `-0` → `0`).

## 2. Project

```ts
type UUID = string;            // RFC 9562 UUIDv7, generated by the adapter, never by a handler
type Slug = string;            // ^[a-z0-9]+(?:-[a-z0-9]+)*$, max 64

type ProjectV1 = {
  schemaVersion: "1.0";
  id: UUID;
  name: string;                                // 1..120 chars
  revision: number;                            // monotonically increasing; +1 per committed transaction
  designSystem: DesignSystemV1;
  tokens: ColorTokenV1[];
  components: ComponentV1[];
  icons: IconV1[];
  exportProfiles: ExportProfileV1[];
  provenance: ProvenanceRecordV1[];
  extensions?: Record<string, unknown>;        // namespaced, preserved, never interpreted by core
};

type DesignSystemV1 = {
  grid: { width: number; height: number };     // default 24×24
  safeArea: { top: number; right: number; bottom: number; left: number };
  style: "outline" | "filled" | "duotone" | "custom";
  stroke: { width: number; cap: LineCap; join: LineJoin; miterLimit: number };
  cornerRadius: number;
  defaultPaintToken: string;                   // usually "currentColor"
  naming: { pattern: "kebab"; reserved: string[] };
  severities: Record<RuleCode, "off" | "info" | "warning" | "error">;
};

type LineCap  = "butt" | "round" | "square";
type LineJoin = "miter" | "round" | "bevel";
type RuleCode = string;                        // registered by the rules package; unknown codes rejected

type ColorTokenV1 = {
  name: string;                                // "currentColor" is built-in and cannot be redefined
  light: string;                               // #RRGGBB or #RRGGBBAA
  dark?: string;
};
```

## 3. Icons and scene

```ts
type IconV1 = {
  id: UUID;
  name: Slug;                                  // unique within project
  aliases: Slug[];
  tags: string[];
  category?: string;
  viewBox: [Coord, Coord, Coord, Coord];
  nodes: SceneNodeV1[];
  variants: VariantV1[];
  accessibility: { kind: "decorative" | "informative"; label?: string };
  font?: { codepoint?: number; glyphName?: string; ligature?: string; advance?: number; lsb?: number };
  recipeRef?: UUID;                            // reserved; Phase 9
  provenanceIds: UUID[];
  ruleOverrides?: Partial<Record<RuleCode, "off" | "info" | "warning" | "error">>;
};

type NodeBase = {
  id: UUID;
  name?: string;
  transform?: MatrixV1;                        // quantized
  visible: boolean;
  locked: boolean;
  opacity?: number;                            // 0..1, quantized to 0.001
  role?: "primary" | "secondary";             // duotone layering
};

type SceneNodeV1 =
  | NodeBase & { type: "path";   path: PathDataV1; fill?: PaintV1; fillRule: "nonzero" | "evenodd"; stroke?: StrokeV1 }
  | NodeBase & { type: "group";  children: SceneNodeV1[] }
  | NodeBase & { type: "rect";    x: Coord; y: Coord; width: Coord; height: Coord; rx: Coord; ry: Coord; fill?: PaintV1; stroke?: StrokeV1 }
  | NodeBase & { type: "ellipse"; cx: Coord; cy: Coord; rx: Coord; ry: Coord;     fill?: PaintV1; stroke?: StrokeV1 }
  | NodeBase & { type: "line";    x1: Coord; y1: Coord; x2: Coord; y2: Coord;     stroke: StrokeV1 }
  | NodeBase & { type: "polyline"; points: Coord[]; closed: boolean; fill?: PaintV1; stroke?: StrokeV1 }
  | NodeBase & { type: "instance"; componentId: UUID; arguments: Record<string, ParamValueV1> };

/** ADR-019: structured, absolute, quantized. `d` strings exist only at import/export edges. */
type PathDataV1 = SubpathV1[];
type SubpathV1 = { start: [Coord, Coord]; segments: SegmentV1[]; closed: boolean };
type SegmentV1 =
  | { k: "L"; to: [Coord, Coord] }
  | { k: "Q"; c: [Coord, Coord]; to: [Coord, Coord] }
  | { k: "C"; c1: [Coord, Coord]; c2: [Coord, Coord]; to: [Coord, Coord] };
// Elliptical arcs are converted to cubics at import (reported as info diagnostic `import.arc-converted`).

type PaintV1  = { kind: "none" } | { kind: "token"; token: string } | { kind: "color"; value: string };
type StrokeV1 = { paint: PaintV1; width: Coord; cap: LineCap; join: LineJoin; miterLimit: number; dash?: Coord[] };
type MatrixV1 = [number, number, number, number, Coord, Coord];   // a b c d e f; a..d quantized to 1e-6
```

Literal `PaintV1` color values are sRGB `#RRGGBB` or `#RRGGBBAA`. This excludes CSS `url(...)` and external resource references from the project model; `none` and token paints use their dedicated variants.

Constraints: `rx ≤ width/2`, `ry ≤ height/2`; `polyline.points.length` even and ≥ 4; IDs unique across the whole project; `instance` cycles rejected; maximum nesting depth 32. Stroke `dash` is permitted in SVG/PNG/ICO output and is a **font-export error** (fonts cannot represent dashes without outlining every dash; diagnostic `font.dash-unsupported`).

## 4. Variants and components

```ts
type VariantV1 = {
  id: UUID;
  name: Slug;
  dimensions: { style?: "outline" | "filled" | "duotone"; size?: number; state?: string; [custom: `x-${string}`]: string | number | undefined };
  overrides: VariantOverrideV1[];             // applied in order to the base icon's nodes
};

type VariantOverrideV1 =
  | { op: "hide"; nodeId: UUID }
  | { op: "replaceNode"; nodeId: UUID; node: SceneNodeV1 }
  | { op: "setStroke"; nodeId: UUID; stroke: StrokeV1 | null }
  | { op: "setFill"; nodeId: UUID; fill: PaintV1 | null }
  | { op: "setTransform"; nodeId: UUID; transform: MatrixV1 };

type ParamValueV1 = number | string | boolean;
type ComponentV1 = {
  id: UUID; name: Slug;
  parameters: { name: string; type: "number" | "string" | "boolean"; default: ParamValueV1; min?: number; max?: number }[];
  bindings?: { parameter: string; nodeId: UUID; field: "stroke.width" | "rx" | "ry" | "visible" }[];
  nodes: SceneNodeV1[];                       // V1: numeric parameters bind to stroke width/radius; boolean to visibility
};
```

Bindings target nodes owned by the component, including nodes in nested groups. Each target field may be bound once. Numeric parameters bind to `stroke.width`, `rx` or `ry`; boolean parameters bind to `visible`. The target must support the field and already have a stroke for `stroke.width`. Instance arguments override defaults without changing stored component nodes; export rejects geometry that violates node constraints. `bindings` is optional for existing v1 documents, so opening them needs no migration. A parameter with no binding still produces `svg.instance.parameters-unbound` at export.

## 5. Export profiles and provenance

```ts
type ExportProfileV1 =
  | { id: UUID; name: Slug; target: "svg";    options: { precision: 0|1|2|3; sizeAttrs: boolean; paintMode: "currentColor" | "tokens" | "resolved"; metadata: boolean } }
  | { id: UUID; name: Slug; target: "sprite"; options: { idPrefix: string; precision: 0|1|2|3 } }
  | { id: UUID; name: Slug; target: "png";    options: { sizes: number[]; theme: "light" | "dark"; padding: number } }
  | { id: UUID; name: Slug; target: "ico";    options: { sizes: (16|24|32|48|64|128|256)[]; theme: "light" | "dark" } }
  | { id: UUID; name: Slug; target: "font";   options: { family: string; formats: ("otf"|"ttf"|"woff2")[]; unitsPerEm: 1000|1024|2048; puaStart: number; ligatures: boolean; cssPrefix: string; mergeLayers?: boolean } }
  | { id: UUID; name: Slug; target: "project"; options: Record<string, never> };

type ProvenanceRecordV1 = {
  id: UUID; source?: string; author?: string;
  license?: string;            // SPDX expression or "UNKNOWN"; never guessed
  attribution?: string; originalSha256?: string; importedAt?: string; modified: boolean;
};
```

For font profiles, `mergeLayers` defaults to `false` when absent. A `true` value explicitly opts into merging duotone layers into one monochrome glyph. Existing profile data without the field keeps the error behavior and needs no migration.

## 6. Command envelope (ADR-026)

```ts
type CommandEnvelope<TType extends CommandType = CommandType> = {
  commandVersion: "1.0";
  commandId: UUID;                 // idempotency key: a repeated commandId returns the original result
  projectId: UUID;
  type: TType;
  payload: CommandPayload<TType>;  // includes every new ID the command will create
  expectedRevision?: number;       // optimistic concurrency; mismatch → error `revision.conflict`
  dryRun?: boolean;                // compute result + patch summary; never commits, never enters history
  confirmsDryRun?: UUID;           // commandId of the dry-run this apply confirms (required by policy for batch/destructive non-UI actors)
  issuedAt: string;                // RFC 3339; informational only — never read by handlers or compiler
  actor: { kind: "user" | "cli" | "mcp" | "webmcp" | "ai-proposal"; id?: string };
};

type CommandResult = {
  commandId: UUID;
  status: "applied" | "dry-run" | "rejected";
  revision: number;                // revision after apply (or unchanged)
  changedIds: UUID[];
  patchSummary: { added: number; updated: number; removed: number; iconsAffected: UUID[] };
  diagnostics: DiagnosticV1[];
  artifacts?: ArtifactRefV1[];     // compile.run only
};

type DiagnosticV1 = {
  severity: "info" | "warning" | "error";
  code: string;                    // stable, documented, e.g. "rule.stroke-width-mismatch"
  message: string;                 // human text; never parsed by machines
  objectId?: UUID;
  location?: { iconId?: UUID; nodeId?: UUID; segmentIndex?: number; sourceLine?: number; sourceColumn?: number };
  fix?: CommandEnvelope;           // a proposed command, always dry-runnable
};

type ArtifactRefV1 = { path: string; mediaType: string; bytes: number; sha256: string };
```

Handler contract: `(project: ProjectV1, cmd: CommandEnvelope) → { project, patches, inversePatches, result }`. Handlers are pure: no clock, no randomness, no I/O, no ID generation.

## 7. V1 command registry

| Command | Payload (abridged) | Notes |
|---|---|---|
| `project.create` | `{ id, name, designSystem? }` | Only command valid without an existing project. |
| `project.rename` | `{ name }` | |
| `project.updateDesignSystem` | `{ patch: Partial<DesignSystemV1> }` | Does not rewrite icons; use `set.applyStyle`. |
| `token.upsert` / `token.remove` | `{ token }` / `{ name }` | Remove fails if referenced (`token.in-use`). |
| `icon.add` | `{ icon: IconV1 }` | Created from blank, primitive or library. |
| `icon.importSvg` | `{ icon: IconV1, provenance: ProvenanceRecordV1, diagnostics: ImportDiagnosticV1[] }` | The import worker validates source, assigns stable IDs and converts it to a canonical icon before dispatch. The icon references exactly this provenance record, whose `originalSha256` is the lowercase SHA-256 of the original SVG bytes. `ImportDiagnosticV1` is `{ code: string, severity: "info"\|"warning", message: string }`. The command handler inserts the icon and provenance in one reversible transaction and returns the diagnostics. The original bytes are stored at `originals/<sha256>.svg` in the same durable IndexedDB transaction as the journal entry and included in project backups. Raw source and ID seeds do not enter the command journal. |
| `icon.remove` / `icon.rename` / `icon.duplicate` | `{ iconId }` / `{ iconId, name }` / `{ iconId, newIconId, idMap }` | |
| `icon.updateMetadata` | `{ iconId, patch }` | Tags, aliases, accessibility, font mapping. |
| `node.add` / `node.remove` | `{ iconId, parentId?, index, node }` / `{ iconId, nodeIds }` | |
| `node.update` | `{ iconId, nodeId, ops: NodeUpdateOp[] }` | Typed field ops; no generic merge. |
| `node.reorder` | `{ iconId, nodeId, parentId?, index }` | Move a node to a destination sibling array; `index` is measured after removal. The destination parent must be a group outside the moved subtree. |
| `node.group` | `{ iconId, nodeIds, groupId, index }` | Selected nodes must be siblings. Creates a neutral group (visible, unlocked, no transform/opacity/role) at `index` in that sibling array after selected nodes are removed. Child order follows scene order. |
| `node.ungroup` | `{ iconId, groupId }` | Expands a neutral group at its current position. Rejects groups with visual properties or variant references to the group ID. |
| `selection.transform` | `{ iconId, nodeIds, matrix }` | Matrix is pre-computed and quantized by the adapter. |
| `path.editSegments` | `{ iconId, nodeId, edits }` | Node editing in Expert Mode. |
| `node.boolean` | `{ iconId, nodeIds, op: "union"\|"subtract"\|"intersect"\|"exclude", resultId }` | Inputs must be closed and stroke-free; else `boolean.invalid-input`. |
| `node.outlineStroke` | `{ iconId, nodeIds, resultIds }` | Uses `IOutlineEngine` (ADR-022). |
| `source.replaceIcon` | `{ iconId, source, idHints }` | Live SVG editor; ID-preserving reconciliation. |
| `variant.add` / `variant.update` / `variant.remove` | | |
| `component.add` / `component.update` / `component.remove` / `component.instantiate` | | |
| `set.applyStyle` | `{ iconIds, changes: StyleChange[] }` | The batch command. Expected to be run with `dryRun: true` first by every UI. |
| `rule.applyFix` | `{ diagnostic }` | Executes `diagnostic.fix`. |
| `exportProfile.upsert` / `exportProfile.remove` | | |
| `history.undo` / `history.redo` | `{}` | Operate on transactions, not individual patches. |

`NodeUpdateOp` includes `setFill`, `setStroke`, `setCornerRadius`, `setVisible`, and `setLocked`. The corner-radius operation is `{ op: "setCornerRadius", radius: number }`; it applies only to an unlocked rectangle, sets both `rx` and `ry`, and rejects values outside `0 ≤ radius ≤ min(width, height)/2`. Visibility and lock operations use `{ op, value: boolean }`. A locked node accepts only `setLocked` with `value: false`; other edits remain blocked. Operations remain one reversible node patch.

**Queries** (no revision change, not journaled): `project.summary`, `icon.list`, `icon.get`, `rule.validate`, `compile.run`, `compile.capabilities`, `exportProfile.list`, `command.schemas`. `compile.run` is a query: it never mutates the project (ADR-008).

Persistence (`open`, `save`, `saveAs`, `export package`) is a repository concern exposed by adapters, not a command.

## 8. Evolution
- Readers support the current schema and at least one previous minor version.
- Migrations are pure, ordered, fixture-tested, and quantize their output.
- A future major version opens read-only with "export original package".
- Command versions evolve independently of the schema version; a breaking payload change introduces `commandVersion: "2.0"` for that command while `1.0` remains accepted for one minor product release.
